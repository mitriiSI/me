# Метросигнал

Веб-приложение для поездок на метро. Строит маршруты через выбранные станции, сохраняет схемы в кэше браузера и подаёт звуковой сигнал перед пересадкой и конечной.

## Локальный запуск

В корне репозитория выполни `python3 -m http.server 8000` и открой `http://localhost:8000`. Для геопозиции и офлайн-режима на iPhone открывай приложение по HTTPS.

Приложение состоит из статических файлов и запускается без сборки.
